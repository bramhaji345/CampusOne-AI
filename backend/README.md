# backend

This folder is empty of API source on purpose.

Each teammate owns a numbered folder (`01-AI`, `02-Student`, `03-Faculty`, `04-Admin`, `05-Outpass-Security`, `06-Auth-Database`). Copy your `backend/` files here when merging so there are no duplicate routes, controllers, or Prisma files at the repo root.

Do not commit `.env`. Use `.env.example` from your module folder as the template.
